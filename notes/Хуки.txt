Состояние - это способность изменяться со временем посредством использования внутренних переменных.
Хук (ключок) - это специальная функция в React, которая позволяет "подцепляться" к разным возможностям React из функциональных компонентов.
1. Вызывает хуки только на верхнем уровне компонента (нельзя внутри if, циклов, вложенных функций)
2. Вызывать хуки только в React-функцияхя
 - в функциональных компонентах
 - в собственных хуках

useState - это хук (функция) из React, который позволяет компоненту "помнить" какое-то значение между перерисовками. Без useState каждый раз, когда компонент перерисовываться, все переменные внутри него создаются заново ->  сбрасываются. С useState значение сохраняется React`ом между рендерами.
const [состояние, функция_изменения] = useState(начальное_значение);

useState всегда возвращает массив из двух элементов (кортеж). Используем деструктуризацию, чтобы сразу дать имена этим двум элементам.

const [countLikes, setCountLikes] = useState(0);
countLikes - текущее значение состояния
setCountLikes - функция для изменения этого значения
useState(0) -  вызов хука с начальным значением

useEffect отвечает за выполнение побочных эффектов в функциональных компонентах. Побочные эффекты - это все то, что выходит за рамки простого возврата JSX:
	- запросы к серверу
	- подписка на события
	- работа с DOM напрямую
	- установка таймеров/интервалов
	- запись в localStorage
	- изменение title страницы
	- легирование
И многое другие.

useEffect(setup, dependencies)

useEffect(() => {
	код, который нужно выполнить после рендера
	обычно здесь побочные эффекты
 render () => {
	cleanup-функция (опционально)
	выполняется перед следующим вызовом эффекта
	и обязательно при ремонтировали компоненты
 }
}, [dependencies]) массив зависимостей

Хук useRef позволяет "запоминать" какое-то значение между рендерами компонента, не вызывая при этом перерисовки при его изменении.
- возвращает объект с единственным свойством .current
- .current можно читать и записывать в любое время
- изменение .current не вызывает перерендер компонента
- значение .current сохраняется между рендерами
- при первом рендере .current = переданному initialValue
- при разминировании компонента ref не очищается автоматически
- инициализация происходит один раз useRef(expensiveFunction()) - функция вызывает только при первом рендере
- один и тот же объект { current: ... } живет всю жизнь компонента

Подъем состояния - это ситуация, когда несколько компонентов нуждаются в доступе к одному и тому же состоянию и вместо того, чтобы дублировать это состояние в каждом компоненте, мы понимает (lifting) его на самый ближайший общий родительский компонент.
